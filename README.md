# Ginamu Aesthetics

Premium aesthetics and wellbeing website for Ginamu Aesthetics, Westlands, Nairobi.

## Phase 1
- Editorial floating navbar
- Hero + primary booking CTA
- Responsive image collage using approved Ginamu imagery
- Brand palette extracted from Ginamu logo (#641e2b maroon / #687377 ash)
- Pointer-reactive ambient light and CSS entrance motion

## Stack
Next.js 16, React 19, TypeScript, Tailwind CSS v4. GSAP/Motion/Lenis and Sanity CMS will be added as the build progresses.
